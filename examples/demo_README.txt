示例数据说明 / Demo dataset
============================================================
随机种子 20261028，基因组完全合成，不含任何真实物种序列。
染色体长度：chr1=12000, chr2=6000, chrScaf=3000

每个基因覆盖的情形：
  g1   g1.1     chr1    +  正链、3 外显子、含 5′/3′ UTR；另有可变剪接转录本 g1.2
  g1   g1.2     chr1    +  g1 的第二转录本（跳过外显子 2）
  g2   g2.1     chr1    -  负链、3 外显子，用于验证反向互补与片段倒序
  g3   g3.1     chr2    +  单外显子（应报告无内含子）
  g4   g4.1     chrScaf -  贴近 scaffold 起点，上游只能取到 50 bp（边界截断）
  g5   g5.1     chr1    +  注释只有 CDS、没有 exon（外显子需由 CDS 推导）
  g6   g6.1     chr2    +  非编码转录本（无 CDS，不应报错）
  g7   g7.1     chr1    +  含 start>end 的异常 exon 行（解析器应交换并警告）
  g8   g8.1     chrUn_1 +  位于 FASTA 中不存在的序列 chrUn_1（用于验证 ID 不匹配报错）
  g9   g9.1     chr2    +  两个外显子在基因组上重叠（注释异常，不应造出负长度内含子）
  g10  g10.1    chr1    +  注释缺少 gene 行（由转录本反推基因区间）

参考 mRNA 文件里 g2 故意少 1 个碱基、g3 故意替换 1 个碱基；
g6 有两条等长候选，用来触发『需要人工检查』。
参考 CDS 文件里 g3 故意插入 3 bp，用于验证 indel 定位。

原始坐标：GFF3/GTF 为 1-based 闭区间。
